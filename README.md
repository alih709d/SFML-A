## Controls
- Mouse: click a fruit to select it, then click a neighbouring fruit to swap
- Up/Down + Enter: menu
- Esc: save and return to the menu

## How to run
Open the solution in Visual Studio (SFML 3 set up), press Ctrl+F5.
